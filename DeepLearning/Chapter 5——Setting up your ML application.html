              5.1 Train/dev/test sets

              通常我们会将数据集分为三个部分：训练集、验证集（开发集）、测试集。

              在以前的机器学习时代，我们通常会选择数据配比为70%训练集、30%测试集，或者当指定了开发集的时候，这个比例可能为 6:2:2 。然而，在现如今的大数据时代，考虑到开发集的目的是从不同的算法当中选择出表现最好的算法，因此我们并不需要如此多的开发集，例如，当我们的样本量为 1000000 时，也许只需要有 10000 个样本的开发集就行了，此时的比例可能为 98:1:1 。

              在实际当中，很多时候数据集的训练集和测试集会出现异分布的情形，也称为 mismatch 。例如，训练集可能是从网页上爬取的猫猫图片，但是开发集和测试集上面有很多用户上传的模糊的猫猫图片。当出现这种情况的时候，我们需要记住的是：保持开发集和测试集的分布是一致的。

              5.2 Bias and Variance

              下面的三张图展示了拟合的三种情形：欠拟合、恰好拟合以及过拟合。欠拟合的精度不高，因此我们说它是高偏差的，但是它同时对于训练集和开发集都有差不多的精度，因此是低方差的；对于过拟合，虽然它在训练集上表现良好，但是在开发集上表现糟糕，因此我们说它是高方差的。

              需要注意的是：

              1. 偏差的大小是训练集误差（train set error）相对于基准误差（optimal error/base error）的，当训练集误差和基准误差接近的时候，我们称之为低偏差的，反之称为高偏差的。

              2. 方差的大小是比较训练集误差和开发集误差（dev set error）之间相对误差，当开发集误差远远大于训练集误差的时候，我们称之为高方差的，反之称为低方差的。

              基于以上对于偏差和方差的讨论，我们可以得到对于机器学习的一种基本准则，这使得我们对于问题的分析更加清晰。

              1. 算法是否是高偏差的？

                采用更大的网络结构，训练更长的时间。

              2. 算法是否是高方差的？

                采用更多的数据，正则化，更大的网络结构。

              5.3 Regularization

              这里我们来讨论一下正则化（regularization），这对应于上面我们所说的过拟合的情况，即高方差。

              对于逻辑回归问题而言，我们的目标为 minw,bJ(w,b) ，其中 w∈Rnx,b∈R ，而正则化指的就是在目标函数中加入一个正则项：

              J(w,b)=1m∑i=1mL(y^(i),y(i))+λ2m∥w∥22⏟正则项,

              这称之为 L2 regularization ，其中 ∥w∥22=∑j=1nxwj2=w⊤w 。

              实际上，我们还有 L1 regularization ∥w∥1=∑j=1nx|w| ，使用 L1 regularization 会让参数变得稀疏（sparse），这意味着有很多的 w 都是 0 。

              接下来我们考虑神经网络当中的正则化：

              J(w[1],b[1],⋯,w[L],b[L])=1m∑i=1mL(y^(i),y(i))+λ2m∑l=1L∥w[l]∥F2⏟正则项,

              其中 ∥w[l]∥F2=∑i=1n[l−1]∑j=1n[l](wij[l])2 ，需要注意的是，此时当我们进行反向传播的时候，dw[l] 需要变为

              dw[l]=(from back-prop)+λmw[l].

              NN 的正则化有时也称为权重衰减（weight decay），这是因为

              w[l]:=w[l]−αdw[l]=w[l]−α[(from back-prop)+λmw[l]]=(1−αλm)w[l]−α(from back-prop),

              可以看出经过正则化后的参数总是比原来小一些。

              现在，一个自然的问题是：为什么正则化能够减少过拟合呢？

              一个直观的例子是，当我们在深层网络当中使用正则化的时候，考虑一个极端情形，当正则项的权重非常大的时候，这时的深度网络当中的很多参数会被压缩为 0，这意味着一个深度的神经网络可能只有少量的神经元是有用的，极端情形下退化到线性网络的情况，这就解释了为什么正则化可以减少过拟合。

              一个常见的正则化方法是 Dropout，下面我们简单介绍一下 Dropout regularization。

              Dropout 意味着对于隐藏层中的一些神经元，我们会设置一个概率，这些被选中的节点将以一定的概率不会进入实际的计算当中，这个时候我们得到的是一个小得多的网络，因此我们也可以理解为什么这是一种正则化技术。

              需要注意的是：

              1. Dropout 本质上为一种正则化技术，因此当我们的模型还没有过拟合的时候，仍不建议直接使用 Dropout。

              2. Dropout 具有正则化效果的另外一种解释为，对于一个神经元而言，它不能依赖任何一个输入的特征，因此必须将权重分散开来。

              另外，还有一些常见的正则化方法可以简单介绍一下：

              虽然说增加数据是减少过拟合很好的方法，但是很多时候我们就是无法获得更多的数据，这个时候数据增强（Data augmentation） 可以帮助我们获得更多的数据。例如对于一张猫的图片而言，我们可以对原始的照片进行翻转或者裁剪，得到一张新的图片。

              早停机制（Early stopping）：在训练的时候我们也许会发现，虽然训练集上的损失函数一直在减小，但是随着训练的深入，验证集上的损失却开始上升，早停机制指的就是在合适的地方提前停止训练，以或者训练集误差和验证集误差都比较小的结果。

              早停机制并不满足正交化的原则，因为早停机制同时影响了两个任务——优化代价函数以及防止过拟合，因此早停机制也许在算力足够的情况下是不建议施行的。

              5.4 Normalizing inputs

              训练神经网络的时候，有一种加速训练过程的方法，那就是对输入进行归一化（normalize）。这里所说的归一化实际上是统计中所说的标准化，即将输入的特征转化为满足均值为 0，方差为 1的分布。

              5.5 Vanishing/exploding gradients and Weight initialization

              当训练深度神经网络的时候，有时我们会遇到梯度消失或者爆炸的问题，下面我们将简单的看一个例子明白这是如何发生的。

              假设我们在训练一个深度网络，使用的激活函数是简单的恒等映射 g(z)=z ，并且 b[l]=0 。此时，输出为

              y=w[L]w[L−1]⋯w[2]w[1]x.

              那么当我们的 w[l]=[1.5001.5] 时，梯度会指数上升，很快就会出现梯度爆炸的情形，梯度消失的情形也是类似的，只是把对角线上的元素设置为小于 1 。

              一种也许有效的方法就是更细致的初始化你的神经网络，现在让我们考虑一个简单的单神经元模型。

              此时有

              z=w1x1+w2x2+⋯+wnxn,

              当 n 很大的时候，我们当然期望 wi 应该需要小一点，此时一个显然可选的初始化就是 wi∼N(0,1n) 。当使用ReLU为激活函数的时候，此时用 2n 会更好一些。

              另外，当使用tanh激活函数的时候，我们会用 1n[l−1]​ ，这称之为 Xavier 初始化。
