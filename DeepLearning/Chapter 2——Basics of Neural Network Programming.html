            前向传播和反向传播——以逻辑回归为例

            2.1 Binary Classification and Logistic Regression

            逻辑回归是一个二元分类算法，假设我们希望利用一个模型来判断一张图片是否是猫的图片。那么，给定 x∈Rnx ，我们希望得到 y^=P(y=1|x) ，即图片为猫的概率，并且显然有 0≤y^≤1 。

            若我们希望利用逻辑回归来实现这一点，则参数为 w∈Rnx,b∈R ，输出为

            y^=w⊤x+b，

            然而逻辑回归的输出很难满足输出值在 [0,1] 之间的条件，因此我们这里使用 Sigmoid 激活函数，即输出为

            y^=σ(w⊤x+b).

            Sigmoid 函数为 σ(z)=11+e−z ，图像为

            为了更好的训练模型的参数 w 和 b ，我们需要定义一个代价函数（cost function） ，它描述了整个模型的参数 w 和 b 在训练集上的表现。

            给定训练集 {(x(1),y(1)),…,(x(m),y(m))} ，我们希望 y^(i)≈y(i) ，我们会定义一个损失函数（Loss Function）：

            L(y^,y)=12(y^−y)2,

            然而实际上当我们利用这个损失函数对参数进行优化的时候，由于参数空间是高度非凸（non-convex）的，因此当利用梯度下降进行优化的时候很有可能会收敛到局部最优解。所以，在这里我们使用的损失函数是：

            L(y^,y)=−(ylog⁡y^+(1−y)log⁡(1−y^)).

            • 当 y=1 时，有 L(y^,y)=−log⁡y^ ，我们希望 log⁡y^ 尽可能大，即 y^ 尽可能大，而 0≤y^≤1 ，因此 y^→1 。

            • 当 y=0 时，有 L(y^,y)=−log⁡(1−y^) ，我们希望 log⁡(1−y^) 尽可能大，即 1−y^ 尽可能大，而 0≤y^≤1 ，因此 y^→0 。

            此时的代价函数为：

            J(w,b)=1m∑i=1mL(y^(i),y(i))=−1m∑i=1m(y(i)log⁡y^(i)+(1−y(i))log⁡(1−y^(i))).

            梯度下降（Gradient Descent）的简单公式实现为 w:=w−α∂J(w,b)∂w ，其中 α 为学习率（learning rate）。

            2.2 Logistic Regression on m examples

            接下来我们将会演示如何在训练集上利用梯度下降实现逻辑回归参数的更新。

            假设我们具有两个特征 w1,w2 ，并且使用上面所说的交叉熵损失函数，参数的更新可以表现为下面的循环。

            # 初始化梯度，代价函数为0
            dw1 = 0, dw2 = 0, db = 0, cost = 0
            

            for j in range(m):
              z_j = w1 * x1_j + w2 * x2_j + b
              a_j = 1 / (1 + np.exp(-z_j))  # sigmoid函数
            

              cost += - (y_j * np.log(a_j) + (1 - y_j) * np.log(1 - a_j))  # 交叉熵损失
            

              dz_j = a_j - y_j  # 计算梯度
              dw1 += dz_j * x1_j
              dw2 += dz_j * x2_j
              db += dz_j
            

            cost = cost / m  # 计算平均值
            dw1 = dw1 / m
            dw2 = dw2 / m
            db = db / m
            

            w1 = w1 - learning_rate * dw1  # 更新参数
            w2 = w2 - learning_rate * dw2
            b = b - learning_rate * db
            dz(i)=dJdz(i)=dJda(i)da(i)dz(i)=−(y(i)a(i)−1−y(i)1−a(i))⋅a(i)(1−a(i))=−y(i)(1−a(i))+a(i)(1−y(i))=a(i)−y(i)

            梯度的计算类似的利用链式法则。

            为了让计算更加的高效，我们引入了向量化（vectorization）。这是基于两个for loop的逻辑回归实现，

            Z=w⊤X+b=np.dot(w⊤,X)+bA=σ(Z)dZ=A−Ydw=1mXdZ⊤db=1mnp.sum(dZ)w:=w−αdwb:=b−αdb

            其中 X 的每一列为 x(i) ，Z 的每一列为 z(i) ，α 为学习率。

            2.3 Broadcasting in Python

            Broadcasting 是一种可以使得 python 运行的更快的技术，我们来详细看一下。（具体代码可见 broadcasting-example.ipynb）

            import numpy as np
            

            A = np.array([[56.0, 0.0, 4.4, 68.0],
                          [1.2, 104.0, 52.0, 8.0],
                          [1.8, 135.0, 99.0, 0.9]])
            print(A)
            

            cal = A.sum(axis=0)  # 对矩阵的垂直方向求和
            print(cal)
            

            # A为一个(3,4)的矩阵，而cal为一个(1,4)的矩阵，因此cal会被广播为一个(3,4)的矩阵来进行除法运算
            percentage = 100*A/cal.reshape(1, 4)  
            print(percentage)

            广播的规则为每一维要么相同，要么其中一个为1。

            2.4 A note on python/numpy vectors

            首先我们来看一个例子，见 python-numpy-example.ipynb 。

            import numpy as np
            

            a = np.random.randn(5)  # 产生5个高斯随机数
            print(a)
            print(a.shape)  # 这是一个秩为1的数组，rank 1 array
            

            print(a.T)  # rank 1 array 的转置看起来有一些奇怪，它和原数组是一样的
            

            print(np.dot(a, a.T))  # 计算a和a的转置的点积，结果是一个标量
            

            a = np.random.randn(5,1)  # 这是一个真正的矩阵
            print(a)
            print(a.shape)
            print(a.T)
            print(np.dot(a, a.T))

            原则上，我们使用向量或者矩阵的表达形式，而不使用 rank 1 array，因此当我们不确定变量的维度时，可以使用断言：

            assert(a.shape == (5,1))

            亦或者为了保证维度是正确的，可以使用 reshape 。
