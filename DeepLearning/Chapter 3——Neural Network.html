          3.1 Computing a Neural Network's Output

          这一节我们研究利用神经网络进行输出的细节，我们将会发现，这只是将逻辑回归进行多次的重复。

          在逻辑回归当中，一个圆代表了两步计算，分别为：

          z=w⊤x+b,a=σ(z).

          左图的神经网络只是把这一步进行了很多次，同时我们需要做一些记号上的说明，对于这个两层的神经网络，隐藏层为第一层，输出层为第二层，而输入层不计入神经网络的层数，或者称为第零层。每一层的元素的上标表示层数，下标表示第几个节点（node），例如 a3[1] 表示第一层的第3个节点。

          第一层的计算可以这样表示：

          z1[1]=w1[1]⊤x+b1[1],a1[1]=σ(z1[1])z2[1]=w2[1]⊤x+b2[1],a2[1]=σ(z2[1])z3[1]=w3[1]⊤x+b3[1],a3[1]=σ(z3[1])z4[1]=w4[1]⊤x+b4[1],a4[1]=σ(z4[1])

          正如我们之前讨论过的，直接计算是很麻烦的，因此我们需要进行向量化（vectorization）：

          Giveninput x:(z[1])4×1=(W[1])4×3(x)3×1+(b[1])4×1a[1]=σ(z[1])z[2]=W[2]a[1]+b[2]a[2]=σ(z[2])

          下标的 4×1 表示矩阵的维度。

          目前我们已经清楚了神经网络对于单个训练实例的预测是如何进行的，接下来我们进一步研究多个训练实例的向量化。

          对于单个训练实例我们可以实现

          x⟶a[2]=y^,

          对于多个训练实例我们可以类似的实现

          x(1)⟶a[2](1)=y^(1)x(2)⟶a[2](2)=y^(2)⋯x(m)⟶a[2](m)=y^(m).

          若我们需要实现上述流程，那么我们需要一个 for loop：

          for i=1 to m:z[1](i)=W[1]x(i)+b[1]a[1](i)=σ(z[1](i))z[2](i)=W[2]a[1](i)+b[2]a[2](i)=σ(z[2](i))

          而同样的，通过堆叠训练实例，可以实现正确的向量化，即：

          X=[|||x(1)x(2)⋯x(m)|||]∈Rnx×m,

          对 Z 的实现也是类似的，从而可以得到：

          Z[1]=W[1]X+b[1]A[1]=σ(Z[1])Z[2]=W[2]A[1]+b[2]A[2]=σ(Z[2]).

          3.2 Activation Functions

          1. 一般我们总是使用 ReLU 激活函数，并且其表现一般比 Sigmoid 好一些；

          2. 由于 ReLU 在左半部分的导数为 0 ，因此有时也可以尝试 Leaky ReLU，0.01 可以是一个超参数，允许自行调试；

          3. tanh 的激活值接近于 0 ，因此可以先对数据标准化然后再使用 tanh 激活函数；

          4. 对于非负的输出可以使用 ReLU ，除了二分类问题几乎不使用 Sigmoid 激活函数。

          若不使用非线性激活函数，那么一个神经网络所做的只是拟合一个线性函数。

          这一小节我们研究神经网络的反向传播（back propagation），让我们先从简单的单样本开始看起。

          那么对于第二层，如果选用 Sigmoid 激活函数以及交叉熵损失，那么参考Chapter 2就有

          dz[2]=a[2]−y,

          而对于 dW[2]=dLdz[2]⋅dz[2]dW[2]=(a[2]−y)⋅dz[2]dW[2] ，且有 z[2]=W[2]a[1]+b[2] ，因此有

          dz[2]dW[2]=(a[1])⊤.

          db[2] 的推导是类似的，dz[2]db[2]=I 。

          对于第一层，我们有

          dz[1]=dLdz[2]⋅dz[2]da[1]⋅da[1]dz[1]=dz[2]⋅(W[2])⊤⋅g[1]′(z[1]),

          对于第一层剩下的推导也是类似的。

          综上我们可以将单样本和多样本的情形总结为下面的表格。

          1. 单样本（Single Example）输出层（Layer 2）:dz[2]=a[2]−ydW[2]=dz[2]⋅(a[1])⊤db[2]=dz[2]隐藏层（Layer 1）:dz[1]=(W[2])⊤⋅dz[2]⋅g[1]′(z[1])dW[1]=dz[1]⋅x⊤db[1]=dz[1]2. 向量化（Vectorized）J(W[1],b[1],W[2],b[2])=1m∑i=1mL(y^(i),y(i))输出层（Layer 2）:dZ[2]=A[2]−Y(维度:(n[2],m))dW[2]=1mdZ[2]⋅(A[1])⊤(维度:(n[2],n[1]))db[2]=1m∑i=1mdb[2](i)=1mnp.sum(dZ[2],axis=1,keepdims=True)隐藏层（Layer 1）:dZ[1]=(W[2])T⋅dZ[2]⋅g[1]′(Z[1])(维度:(n[1],m))dW[1]=1mdZ[1]⋅X⊤(维度:(n[1],nx))db[1]=1m∑i=1mdb[1](i)=1mnp.sum(dZ[1],axis=1,keepdims=True)

          其中 keepdims=True 是为了保证输出的结果为矩阵，而不是 rank 1 array。
