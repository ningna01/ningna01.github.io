                    • Kalman Filter

                    一、 思想演进：从 Black Box 到 White Box

                    在 Kalman Filter 提出之前，人们通常采用 Black Box (黑盒) 思维来分析系统 (Input-Output)。例如：

                    • Wienar Filter (维纳滤波)：假定输出与输入的关系为 y(n)=f(x(n)⋅θ)。通常将其直接简化为线性模型 θTx(n) 来进行求解。

                    现代滤波理论则发展为 White Box (白盒) 思维，核心原因在于我们可以利用系统的 Prior Knowledge (先验知识) 来建立更加准确的数学模型。

                    二、 状态空间模型 (State Space Model)

                    白盒思维的基础是状态空间模型。对于一般的非线性系统，状态转移和观测过程可以表示为：

                    {xn=fn(xn−1,vn)yn=gn(xn,wn)

                    为了应用标准的卡尔曼滤波，我们需要对其进行线性化处理：

                    {xn=Fnxn−1+vnyn=Hnxn+wn

                    模型变量说明：

                    • 状态变量 (State)：xn 可以是 Non-Stationary (非平稳的)，其维度为 {xk}∈Rm。状态转移矩阵 Fn∈Rm×m。

                    • 观测变量 (Observation)：yn 包含系统外部的测量信息，其维度为 {yk}∈Rn。观测矩阵 Hn∈Rn×m。

                    • 噪声 (Noise)：vn 为过程噪声，wn 为观测噪声。它们被假设为 White Noise (白噪声)，满足以下统计特性：

                      • 零均值：E(vn)=E(wn)=0

                      • 协方差：E(vnvm)=PnIn×n，E(wnwn)=QnIn×n

                    三、 核心流程：递归估计 (Recursive Estimation)

                    卡尔曼滤波的核心目标是通过历史的观测数据集合 {Y1,⋯,Yn} 来最优地估计系统状态 {x1,⋯,xn}。这一过程通过不断地递归实现：

                    • 步骤 1：Prediction (预测)。利用截止到上一时刻的数据 {Y1,⋯,Yn−1} 来预测当前状态 {x1,⋯,xn}。

                    • 步骤 2：Correction (修正)。结合当前时刻的新观测值，利用 {Y1,⋯,Yn} 来修正对 {x1,⋯,xn} 的估计。

                    3.1 预测步骤推导 (Prediction)

                    核心问题： 如何做预测？利用状态方程。 基于正交投影定理，给定观测空间，状态的最优估计等价于状态向量在该空间上的投影：

                    xn|n−1=Proj{Y1,⋯,Yn−1}xn=Proj{Y1,⋯,Yn−1}{Fnxn−1+vn}=FnProj{Y1,⋯,Yn−1}xn−1+Proj{Y1,⋯,Yn−1}vn=Fnx^n−1|n−1

                    利用投影性质 Projba=C⋅b，上式第二行由第一行展开得到。

                    Important

                    命题 3.1 ：（投影系数的最优性） 设 a∈Rm，b∈Rn，求解投影系数 C∈Rm×n 使得 Projba=C⋅b，其本质是最小化均方误差 E|a−Cb|2。则

                    C=E(abT)[E(bbT)]−1

                    证明：

                    对 C 求梯度并令其为零：

                    ∇CE|a−Cb|2=∇CE[aTa−aTCb−bTCTa+bTCTCb]=0⇒E[−abT−abT+2CbbT]=0⇒C=E(abT)[E(bbT)]−1

                    证毕。

                    最终得到先验状态预测方程：

                    x^n|n−1=Fnx^n−1|n−1

                    3.2 修正步骤推导 (Correction)

                    在获得新的观测 Yn 后，更新状态估计：

                    x~n|n=Proj{Y1,⋯,Yn}xn

                    引入新息/残差 (residual) Y~n，它表示当前观测中无法被历史数据预测的部分：

                    Y―n=Yn−Proj{Y1,⋯,Yn−1}Yn=Yn−Proj{Y1,⋯,Yn−1}{Hnxn+wn}=Yn−Hnx^n|n−1

                    将残差与投影结合，得到后验状态修正方程：

                    x^n|n=x^n|n−1+Gn[Yn−Hnx^n|n−1]

                    其中，Gn 被称为 Kalman Gain。

                    四、 最优卡尔曼增益求解

                    接下来确定 Gn 的最优值。 根据正交投影原理，残差正交于所有的原材料 span{Y1,⋯,Yn−1}。

                    1. 计算残差的协方差 E(Y―nY―nT)：

                    展开观测方程 Yn 得：

                    E(Y―nY―nT)=E[(Yn−Hnx^n|n−1)(Yn−Hnx^n|n−1)T]=E[(Hn(xn−x^n|n−1)+wn)(Hn(xn−x^n|n−1)+wn)T]=HnE[(xn−x^n|n−1)(xn−x^n|n−1)T]HnT+E[wnwnT]=HnR^n|n−1HnT+Qn

                    (其中 R^n|n−1 为预测误差的协方差)

                    2. 计算状态与残差的互协方差 E[Y―nxnT]：

                    E[Y―nxnT]=E[(Hn(xn−x^n|n−1)+wn)(xn−x^n|n−1)T]=HnE[(xn−x^n|n−1)(xn−x^n|n−1)T]=HnR^n|n−1

                    3. 求解 Gain： 由上面的命题可得：

                    Gn=E{Y―nxnT}{E{Y―nY―nT}}−1

                    代入上述两项结果，得到卡尔曼增益的最终表达式：

                    Gn=HnR^n|n−1[HnR^n|n−1HnT+Qn]−1

                    五、 协方差的更新律

                    为了使递归能够持续进行，我们需要不断更新误差的协方差矩阵。

                    1. Prediction Error (预测误差协方差更新)：

                    R^n|n−1=E[(xn−x^n|n−1)(xn−x^n|n−1)T]=E[(Fn(xn−1−x^n−1|n−1)+vn)(Fn(xn−1−x^n−1|n−1)+vn)T]=FnE[(xn−1−x^n−1|n−1)(xn−1−x^n−1|n−1)T]FnT+E(vnvnT)=FnR^n−1|n−1FnT+Pn

                    2. Filter Error (滤波误差协方差更新)：

                    代入状态修正方程展开，并利用独立性消除交叉项：

                    R^n|n=E[(xn−x^n|n)(xn−x^n|n)T]=E[(xn−x^n|n−1−GnHn(xn−x^n|n−1)−Gnwn)(xn−x^n|n−1−GnHn(xn−x^n|n−1)−Gnwn)T]=E[((I−GnHn)(xn−x^n|n−1)−Gnwn)((I−GnHn)(xn−x^n|n−1)−Gnwn)T]=(I−GnHn)R^n|n−1(I−GnHn)T+GnQnGnT

                    六、卡尔曼递推公式汇总

                    每一时刻 n 的递推流程：预测 → 求增益 → 修正。

                    1. 预测：x^n|n−1=Fnx^n−1|n−1，R^n|n−1=FnR^n−1|n−1FnT+Pn

                    2. 卡尔曼增益：Gn=HnR^n|n−1[HnR^n|n−1HnT+Qn]−1

                    3. 修正：x^n|n=x^n|n−1+Gn[Yn−Hnx^n|n−1]，R^n|n=(I−GnHn)R^n|n−1(I−GnHn)T+GnQnGnT

                    七、 实例应用：短时间内匀加速运动追踪

                    在物理追踪中，假设目标在短时间内匀加速。根据运动学公式：

                    S(n)=S(n−1)+V(n−1)⋅Δt+a(n−1)⋅Δt22

                    我们可以将系统的状态定义为包含位移 S、速度 V 和加速度 a 的向量：

                    (S(n)V(n)a(n))=(1ΔtΔt2201Δt001)(S(n−1)V(n−1)a(n−1))+vn

                    假设我们的观测设备只能测量到位移 S(n)，则观测方程为：

                    S(n)=(1,0,0)(S(n)V(n)a(n))+wn

                    初始化条件： 通常可以设置初始协方差矩阵 R^0|0=I，初始状态向量 x^0|0=0 启动整个递归滤波系统。
